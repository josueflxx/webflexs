Instrucciones
  • El archivo debe ser formato .xlsx.
  • La primera fila debe contener encabezados validos.
  • Activa "Dry run" para simular sin modificar datos.
    • {% if import_type == 'products' %}
  • Productos acepta encabezados flexibles: SKU/Codigo, Nombre/Articulo, Proveedor, Precio/Venta, Costo, Stock, Categoria/Rubro/Subrubro y Activo.
  • Formato SaaS Argentina: Codigo es SKU, Precio Final ($) es el precio de catalogo y Precio ($) queda guardado como precio neto de origen.
  • En el layout completo de SaaS se ignoran estas columnas por seguridad: C, D, F, G, J, K, L, M, N, O, R, S, V, W, X, Y, Z, AA, AB y AC.
  • Campos utiles conservados del layout SaaS: Nro producto, Estado, Nombre, Codigo, IVA, Proveedor, Precio y Precio Final.
  • Por seguridad, actualizar productos existentes conserva las categorias que ya tienen en el sistema.
  • Las categorias del Excel no se crean automaticamente salvo que lo autorices explicitamente abajo.
  • El orden manual del catalogo y del Excel publicado no se modifica por importar o actualizar productos.
  • Compatibilidad vieja: A=SKU, B=Nombre, C=Proveedor, D=Precio, E=Stock, F..J=Filtro_1..Filtro_5.
  • Las celdas vacias no borran datos existentes: solo actualizan campos con valores validos.
    • {% elif import_type == 'abrazaderas' %}
  • Abrazaderas acepta DESCRIPCION/CODIGO/PRECIO o SKU/NOMBRE/PRECIO/STOCK/CATEGORIA.
  • Al actualizar codigos existentes conserva sus categorias actuales y se intenta completar la ficha tecnica.
  • Solo crea categorias si lo autorizas abajo.
  • Las celdas vacias no borran datos existentes.
    • {% endif %}
